## 🐾 About the Project

**Panda Pour** is a front-end café website created with a soft, playful, and aesthetic design inspired by everyone's favorite fluffy friend — **pandas!** 🐼🎋

The goal was to create a website that feels:

🎀 Cute
☁️ Cozy
🍵 Calm
🐼 Playful
☕ Café-inspired

From the welcoming landing section to the menu and café story, every part is designed to make the user feel like they've stepped into a tiny panda café. 🏡🐾
